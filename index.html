ADB & Fastboot Tool

Connect a device in either mode. The tool detects which one it is and shows the matching controls.

Device

Not connected

The picker lists every USB device Chrome can see. For ADB, enable USB debugging on the target and tap Allow on its screen (tick "Always allow" so it only asks once). Close any desktop adb server first, since it holds the USB interface.

ADB: shell

ADB: reboot into a mode

After the device reboots, press Connect again. Bootloader and fastbootd modes will then show the fastboot controls.

ADB: send files

The destination can be a folder (ends with /) or a full file path. Install as APK ignores the destination.

Fastboot: commands

Fastboot: flash image

Flashing the wrong image can brick the device. Sparse images and files larger than the device's max download size aren't supported. The bootloader must be unlocked.
